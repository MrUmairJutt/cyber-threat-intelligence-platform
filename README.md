# CyberSentinel XDR

AI-powered Cyber Threat Intelligence & Detection Platform frontend demo.

This is a frontend-only React application with static/dummy data. It uses a futuristic cybersecurity command-center UI for SOC analysts, ethical hackers, threat intelligence teams, and enterprise security demos.

## Stack

- React
- Vite
- Tailwind CSS
- Framer Motion
- Recharts
- Lucide React

## Features

- Animated hero section with cyber terminal UI
- Sticky responsive navbar
- Live threat dashboard with fake telemetry, counters, circular score, logs, and charts
- Global cyber attack map with animated attack paths and target panels
- Threat feed cards for ransomware, phishing, zero-days, botnets, dark web alerts, and insider threats
- AI analytics section with bar, pie, and prediction charts
- Hacker-style terminal simulation
- Feature, pricing, testimonial, contact, and footer sections
- Matrix rain, cursor glow, animated grid, glassmorphism cards, neon buttons, loading screen, and smooth scrolling

## Run Locally

```bash
npm install
npm run dev
```

Open the local URL printed by Vite, usually:

```text
http://localhost:5173
```

## Build

```bash
npm run build
```

The project has no backend and does not make real network API calls.
